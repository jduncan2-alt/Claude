# DCF (Discounted Cash Flow) Models

Discounted Cash Flow analysis for company valuation.

## Components

A typical DCF model includes:

1. **Revenue Projections**
   - Historical revenue analysis
   - Growth rate assumptions
   - Market size and share analysis

2. **Operating Expenses**
   - COGS projections
   - SG&A expenses
   - R&D spending

3. **Free Cash Flow Calculation**
   - EBITDA
   - Less: Taxes
   - Less: CapEx
   - Less: Change in NWC
   - = Unlevered Free Cash Flow

4. **Discount Rate (WACC)**
   - Cost of equity (CAPM)
   - Cost of debt
   - Capital structure weights

5. **Terminal Value**
   - Perpetuity growth method
   - Exit multiple method

6. **Valuation**
   - Present value of cash flows
   - Present value of terminal value
   - Enterprise value
   - Equity value
