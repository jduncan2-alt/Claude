# Financial Models

This directory contains various financial modeling templates organized by category.

## Directories

- **dcf/** - Discounted Cash Flow models for company valuation
- **lbo/** - Leveraged Buyout models and transaction analysis
- **m_and_a/** - Mergers & Acquisitions analysis models
- **valuation/** - General valuation models and comparable analysis

## Usage

Each subdirectory contains specific models and documentation for that category. Refer to individual README files in each folder for details.
